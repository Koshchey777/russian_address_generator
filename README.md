🇷🇺 **Генератор реалистичных российских адресов с валидными почтовыми индексами**

Современный API для генерации тестовых данных с российскими адресами. Идеально подходит для:
- Тестирования веб-приложений и мобильных приложений
- Заполнения баз данных реалистичными данными
- Демонстраций и прототипирования
- Обучения и хакатонов

## 🌟 Преимущества API

### Для разработчиков:
- ✅ **Реалистичные данные** — настоящие улицы и корректные индексы
- ✅ **Простая интеграция** — REST API с OpenAPI документацией
- ✅ **Гибкая настройка** — фильтрация по городам, типам улиц, диапазонам домов
- ✅ **Высокая производительность** — асинхронный FastAPI
- ✅ **CORS из коробки** — работает с фронтендом

### Для бизнеса:
- 💰 **Экономия времени** — не нужно вручную создавать тестовые данные
- 🔒 **Безопасность** — никаких реальных персональных данных
-  **Масштабируемость** — генерация до 100 адресов за запрос
- 🌍 **Покрытие** — 100+ городов России

## 🚀 Быстрый старт

### Клонирование репозитория

`git clone git@github.com:Koshchey777/russian_address_generator.git`

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск сервера разработки

```bash
uvicorn main:app --reload
```

## ⚙️ Локальная разработка

Поскольку файл с базой данных `data/address.json` является проприетарным и не включен в репозиторий, для локального запуска выполните следующие шаги:

1. Создайте директорию `data` в корне проекта:
   ```bash
   mkdir data
   ```
2. Создайте файл `data/address.json` и добавьте в него данные в формате:
   ```json
   {
     "Москва": {
       "Тверская": ["125009"],
       "Арбат": ["119019"]
     }
   }
   ```
3. Для получения полной версии базы данных или доступа к Production-окружению, пожалуйста, свяжитесь с нами или оформите подписку на ApiHub.
